# tktk Effects vol.2 选用资源

作者：tktk。来源：[Effekseer 官方贡献库页面](https://effekseer.github.io/en/contributes/tktk02/index.html)，原下载包 `https://effekseer.github.io/contributes/tktk02.zip`。

[官方贡献库](https://effekseer.github.io/en/contribute.html) 的当前 Effects Library 部分将这些作品标为 **CC0**，可用于商业项目。许可原文：[CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/)。此处保留来源以便团队追踪；不要把同页旧版资源的不同许可混用。

选用原工程：Blow2、Claw1、Dark2、Gun3、Light1、Light4、Sword3；`.efkproj` 未修改，Parts 保留它们引用的作者纹理以及 Line6、Particle02。游戏内 PNG 为烘焙、裁剪及渐隐版本；色相由独立材质统一。

离线使用 Effekseer for Unity **1.80.7**，工具/运行库为 MIT，其许可独立于作品的 CC0。游戏最终不包含该运行库，也不需要安装它。
