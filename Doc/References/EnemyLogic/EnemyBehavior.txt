1  积木Boss：

 - 行为：
stateDiagram-v2
    [*] --> Idle

    state "Idle/Decide 决策" as Idle
    state "Walk 行走" as Walk
    state "HammerPlayer 锤击-锤玩家" as HammerPlayer
    state "HammerGround 锤击-锤地面" as HammerGround
    state "Throw 投掷" as Throw
    state "Hurt 受伤" as Hurt

    Idle --> HammerPlayer : 近距离 且 CD好
    Idle --> HammerGround : 中距离 且 CD好
    Idle --> Throw : 远距离 且 CD好
    Idle --> Walk : 需接近
    Idle --> Hurt : 受到伤害

    Hurt --> Idle : 动画结束

    Walk --> HammerPlayer : 进入近战距离
    Walk --> HammerGround : 进入中距离
    Walk --> Throw : 远距离且投掷CD好
    Walk --> Idle : 无需接近

    HammerPlayer --> Idle : 动画结束
    HammerGround --> Idle : 动画结束
    Throw --> Idle : 动画结束

 - 全局：
stateDiagram-v2
    [*] --> AnyState

    state "任意状态" as AnyState
    state "Split 分裂" as Split
    state "Angry 生气" as Angry
    state "Dead 死亡" as Dead

    AnyState --> Split : HP≤3/4（第一次）
    AnyState --> Angry : HP<1/2（第二次，打断所有动作）
    Angry --> Split : 生气动画结束
    AnyState --> Split : HP≤1/4（第三次）

    AnyState --> Dead : HP≤0
    Dead --> [*]

        Fly --> Idle : 进入攻击距离 / 决策

    state "Shake 甩毛" as Shake
