# 黑色遮罩与可穿透暗墙方案

> 目标：**没去过的区域显示为黑色**（摄像机看不到后面的关卡），玩家进入后揭开；
> 「可穿透的暗墙」和遮罩用同一次揭示，用于藏隐藏区域。
> 瓦片与装饰层的整体约定见 [关卡瓦片与装饰层方案](关卡瓦片与装饰层方案.md)。

## 1. 三层东西，一次揭示

| 东西 | 放在哪 | 作用 |
|---|---|---|
| `Mask`（遮罩层） | `Grid` 的子物体，Tilemap，order **50**，**无碰撞体** | 用黑瓦片盖住没去过的区域 |
| `SecretWallField` | 挂在 `Grid/Logic` 上 | 声明「哪些瓦片是可穿透暗墙」 |
| `RevealRegion` | 每个房间一个空物体，带 `BoxCollider2D` | 玩家进来 → 清掉本范围内的遮罩 + 揭掉暗墙 |

排序位置（关键）：

| 层 | Order |
|---|---:|
| `Bg_Decor` / `Logic` / 玩家 / `Art` / 敌人 | -20 / -2 / 0 / 1 / 5 |
| **`Mask` 遮罩** | **50** ← 必须高于所有世界美术 |
| 屏幕效果 `LevelRuntime` | 100 |

遮罩低于 50 的话，未探索房间的墙皮会从黑色里透出来，遮罩就白做了。

## 2. 三个瓦片的分工

| 瓦片 | Collider Type | 算不算「实心几何」 | 用途 |
|---|---|---|---|
| `Ground_Logic`（白） | Grid | ✅ | 普通墙 / 地面 |
| `Spike_Logic`（红） | **None** | ❌ 不参与暴露面判断 | 刺，碰到受伤 |
| `Secret_Logic`（青） | **None** | ✅ **参与** | 可穿透暗墙 |
| `Mask_Black`（黑） | None | — | 遮罩，刷在 `Mask` 层 |

暗墙和刺都是「没有碰撞体」，区别在**铺装器怎么看它们**：

- 刺不是几何 → 铺装器跳过它，不给它铺墙皮，也不拿它当墙做暴露面判断；
- 暗墙是几何 → 铺装器**照常给它铺墙皮**，所以外观和普通墙一模一样，看不出破绽。

## 3. 接入步骤

### 3.1 刷遮罩

Tile Palette 选 `Mask_Black`，在 `Mask` 层上把**没去过的区域**涂黑。

### 3.2 刷暗墙

Tile Palette 选 `Secret_Logic`，在 `Grid/Logic` 上把要做暗门的墙格涂成青色。
然后选中 `Grid` 按 **Ctrl+Shift+G** 重铺 —— 暗墙会拿到和普通墙一样的墙皮。

### 3.3 建揭示区域

1. Hierarchy 右键 `Grid` → `Create Empty`，命名如 `RevealRegion_Room01`
2. 加 `Box Collider 2D`，勾上 `Is Trigger`
3. 加 `Reveal Region` 组件
4. 用 Scene 视图的绿色手柄把框拉到**覆盖整个房间** —— ⚠️ **必须把暗墙所在格也框进去**，
   否则暗墙的墙皮不会被销毁
5. 把组件上的两个引用拖上：
   - `Mask` → `Grid/Mask`
   - `Secret Walls` → `Grid/Logic` 上的 `SecretWallField`
6. 玩家引用留空即可（会自动找 `PlayerController`）

一个房间一个 `RevealRegion`；所有区域共用同一张 `Mask` 和同一个 `SecretWallField`。

## 4. 机制细节

- **判定不靠物理**：玩家是 Kinematic 刚体 + `Rigidbody2D.Slide`，默认不产生触发回调，
  所以 `RevealRegion` 只是拿 `BoxCollider2D` 当**范围定义**（方便拖手柄），
  判定是比较坐标。框 `Is Trigger` 会在运行时被强制打开，绝不会挡路。
- **只清自己范围**：一个区域只清掉落在自己框内的遮罩格和暗墙格，所以一张遮罩图能服务整个关卡。
- **暗墙墙皮怎么一起消失**：铺装器把 run 在暗墙边界**切开**（一段要么全是暗墙、要么全是普通墙），
  给暗墙那一段的构件挂上 `SecretArt` 标记；揭示时按范围销毁这些构件。
  不切开的话，一段墙皮会横跨两种格子 —— 揭开时要么留残块、要么在正常墙上开洞。
- **一次性**：`RevealRegion` 揭开后不再重复执行。

## 4.5 刷瓦片一定要先选对「目标层」

> ⚠️ **多场景叠加时特别注意**：Tile Palette 的「目标层」**不会随你切换场景而改变**。
> 你打开 `Level_Center` 后，刷子可能还在往 `Level_Start_01` 的 tilemap 上写 ——
> 表现就是「在新场景里怎么画都没有东西」。
> 切场景后请先确认 Tile Palette 左上角的目标层，或者干脆只开一个场景编辑。

Tile Palette 窗口左上角有个**目标层下拉框**（默认是当前选中的 Tilemap）。刷子只往目标层写：

- 刷遮罩前，先把目标层切到 `Mask`，再选 `Mask_Black`
- 刷刺 / 暗墙前，目标层切到 `Logic`

**选错会怎样**：遮罩刷进逻辑层后，逻辑层凭空多出一堆「看不见的墙」，
铺装器的外露面判断全歪，表现就是**转角整块没有美术**（这次实际遇到的事故）。

出事了跑这两个菜单（选中 `Grid` 再跑）：

| 菜单 | 作用 |
|---|---|
| `Tools/规则游戏/关卡瓦片/① 体检：逻辑层里有哪些瓦片` | 列出逻辑层里的瓦片；混进遮罩就报警 |
| `Tools/规则游戏/关卡瓦片/② 把遮罩瓦片移回 Mask 层` | 按位置搬回去，然后重铺一次 |

铺装器现在也会**自己认出来**：既没被声明成暗墙、`Collider Type` 又是 `None` 的瓦片，
一律按「不是墙」处理并打警告 —— 所以就算刷错了，也不会再把转角挖掉。

## 4.6 进入 / 离开：遮罩会自己恢复

默认行为（`Restore Mask On Exit` = 开）：

| 时机 | 发生什么 |
|---|---|
| 玩家**进入**区域 | 清掉本范围内的遮罩格（记下每格原来是什么），暗墙**永久**揭掉 |
| 玩家**离开**区域 | 按记录把遮罩格**原样补回** |

所以摄像机只会看到玩家当前所在的那块地方，其他区域永远是黑的。

> 暗墙是「世界」，遮罩是「视线」：找到过的暗门不会变回墙，但离开房间后那块地方会重新被遮罩盖住。

关掉 `Restore Mask On Exit` 就退回「揭开一次、之后永久可见」。

### 引用可以留空

`Mask` 和 `Secret Walls` 两个引用**留空也能跑**：

- `Mask` → 自动找同一个 Grid 下名为 `Mask` 的 Tilemap
- `Secret Walls` → 自动找场景里的 `SecretWallField`

只有场景里存在多份、需要指定时，才手动拖。**拖的时候拖的是「挂着组件的那个物体」**
（例如 `SecretWallField` 挂在 `Grid/Logic` 上，就把 `Logic` 拖进去），
不是拖组件本身。

## 4.7 调范围：用「格」而不是 Scale

选中 `RevealRegion` 后，Inspector 里有专门的**范围（按格设置）**：

- `宽（格）` / `高（格）` —— 填数字，立刻写进 `BoxCollider2D.size`（1 格 = 0.5 世界单位）
- `从当前尺寸读回` —— 别人改过之后同步回数字
- `吸附到 0.5 格网格` —— 位置和尺寸都对齐到格线

Scene 视图里还会画一圈**绿色线框 + 四个角手柄**，直接拖角就能改大小（对角固定）。

> ⚠️ **不要用 Transform 的 Scale 改大小**：Scale 会连带缩放子物体，
> 而且碰撞体的 `size` 是本地尺寸，和 Scale 混在一起以后很难算。要改就改上面的格数。

## 4.8 遮罩的外观：编辑器半透明、运行时纯黑

遮罩层挂了一个 `MaskLayer` 组件，它改的是 `Tilemap.color`（和每格颜色相乘，只影响这一张图，不动共享的瓦片资产）：

| 场景 | 透明度 | 为什么 |
|---|---:|---|
| 编辑器里（未运行） | `编辑时透明度`（默认 **0.5**） | 半透明才能看见底下的白盒和美术，方便对位 |
| 进入 Play | **1.0 纯黑** | 真正挡住摄像机，运行时改的值不会写回场景 |
| 退出 Play | 回到 0.5 | 自动恢复，不用手动改 |
| 跑一次 `Ctrl+Shift+G` 铺装 | **1.0 纯黑** | 铺完是「看最终效果」，半透明会让人以为遮罩没生效 |

想切回半透明继续对位：菜单 **`Tools/规则游戏/关卡瓦片/③ 遮罩：半透明 ↔ 纯黑`**（选中 `Grid` 再跑），
或者在 `Grid/Mask` 的 `MaskLayer` 上直接拖 `编辑时透明度` 滑条。

## 4.9 异形房间：一个区域可以拼多个矩形

`RevealRegion` 会收集**自己 + 所有子物体**上的 `BoxCollider2D`，
玩家落在**任意一个**矩形里就算进入。异形房间就加几个子物体拼起来：

1. 选中 `RevealRegion`，Inspector 里点 **＋ 添加矩形** —— 会新建一个子物体 `Box2` 并挂好 BoxCollider2D
2. 每个矩形一行：**宽（格）/ 高（格）** 直接填数字，**吸附** 对齐到 0.5 格，**选中** 跳到 Scene 里定位，**删** 移除
3. Scene 视图里每个矩形都有自己的四角手柄（第 1 个是绿色、其余是蓝色），拖角即可改大小

判定是**逐矩形**算的，不是并集包围盒 —— 两个矩形中间的空隙不会被误判成"在里面"，
遮罩也只会清掉这些矩形覆盖的格子。

> 玩家改为**运行时生成**（PlayerSpawn）之后也没问题：区域找不到玩家会每半秒重试一次，
> 只认已激活的玩家，不会在玩家出生前就把遮罩清掉。

## 5. 容易踩的坑

- ⚠️ **刺不要顶替地板格**。刺不是几何，把地板换成刺玩家会直接掉下去。
  刺要刷在**地板上方那一格**（现在场景里的 49 个刺都是这么放的）。
- ⚠️ **`RevealRegion` 的框要盖住暗墙格**，不然瓦片没了、墙皮还挂着。
- ⚠️ **遮罩层 order 必须高于世界美术**（50），否则没探索的房间会透出来。
- ⚠️ 重铺（Ctrl+Shift+G）会重建 `Art` 和暗墙标记；**遮罩与揭示区域不受影响**，不用重画。
- ⚠️ 遮罩也在 `Grid` 下，`Logic` 的显示开关（Ctrl+Shift+L）不影响它；
  想临时看全图，直接关掉 `Mask` 的 `TilemapRenderer`。

## 6. 验收清单

- [ ] `Mask` 层 order = 50、无碰撞体，未探索区域在 Game 视图里是纯黑
- [ ] `Secret_Logic` 的 Collider Type = `None`（玩家能走穿）
- [ ] 重铺后暗墙的墙皮和相邻普通墙看不出接缝，且该段构件带 `SecretArt`
- [ ] `RevealRegion` 的框覆盖房间 + 暗墙格，两个引用都拖上了
- [ ] 玩家走进房间：遮罩清掉、暗墙瓦片与墙皮同时消失
- [ ] 其他房间仍是黑的（只清自己范围）

## 4.10 揭示时的淡出动画

进入揭示区域时，遮罩**不是瞬间消失**，而是用 0.5~1 秒慢慢淡掉，做出「门被打开」的感觉。

| 字段 | 默认 | 说明 |
| --- | --- | --- |
| `_fadeDuration` | 0.75 | 淡出时长（秒）。设为 0 或负数 = 立刻消失（旧行为） |

### 为什么要另开一层 Tilemap

Tilemap 的透明度是**整层共用一个 `color`**，而每格颜色被瓦片资产上的 `TileFlags.LockColor` 锁住了、改不动。
所以直接淡 `Mask` 的 `color` 会把**整张地图**的遮罩一起淡掉。

做法是：进入时把该区域范围内的黑瓦片从 `Mask` **搬到临时层 `Mask_Fade`**（挂在同一个 Grid 下、排序层与顺序与 Mask 一致），
然后只淡这一层 —— 每帧只写一次 `Tilemap.color`，与格数无关。

- 离开时：临时层清空，瓦片从 `_clearedMask` 记下的内容**原样补回 Mask**（透明度恢复满）
- 淡到一半就离开：直接中断动画、立刻补回，不会留下半透明的残影
- **暂停时不动**：和伤害、物理一致，暂停就是整个世界停住

> 想验证：`RevealRegion` 的 `_fadeDuration` 调大（比如 2 秒）能看清整个过程。
