# 黑色遮罩与可穿透暗墙方案

> 目标：**没去过的区域显示为黑色**（摄像机看不到后面的关卡），玩家进入后揭开；
> 「可穿透的暗墙」和遮罩用同一次揭示，用于藏隐藏区域。
> 瓦片与装饰层的整体约定见 [关卡瓦片与装饰层方案](关卡瓦片与装饰层方案.md)。

## 1. 三层东西，一次揭示

| 东西 | 放在哪 | 作用 |
|---|---|---|
| `Mask`（遮罩层） | `Grid` 的子物体，Tilemap，order **50**，**无碰撞体** | 用黑瓦片盖住没去过的区域 |
| `SecretWallField` | 挂在 `Grid/Logic` 上 | 声明「哪些瓦片是可穿透暗墙」 |
| `RevealRegion` | 每个房间一个空物体，带 `BoxCollider2D` | 玩家进来 → 清掉本范围内的遮罩 + 揭掉暗墙 |

排序位置（关键）：

| 层 | Order |
|---|---:|
| `Bg_Decor` / `Logic` / 玩家 / `Art` / 敌人 | -20 / -2 / 0 / 1 / 5 |
| **`Mask` 遮罩** | **50** ← 必须高于所有世界美术 |
| 屏幕效果 `LevelRuntime` | 100 |

遮罩低于 50 的话，未探索房间的墙皮会从黑色里透出来，遮罩就白做了。

## 2. 三个瓦片的分工

| 瓦片 | Collider Type | 算不算「实心几何」 | 用途 |
|---|---|---|---|
| `Ground_Logic`（白） | Grid | ✅ | 普通墙 / 地面 |
| `Spike_Logic`（红） | **None** | ❌ 不参与暴露面判断 | 刺，碰到受伤 |
| `Secret_Logic`（青） | **None** | ✅ **参与** | 可穿透暗墙 |
| `Mask_Black`（黑） | None | — | 遮罩，刷在 `Mask` 层 |

暗墙和刺都是「没有碰撞体」，区别在**铺装器怎么看它们**：

- 刺不是几何 → 铺装器跳过它，不给它铺墙皮，也不拿它当墙做暴露面判断；
- 暗墙是几何 → 铺装器**照常给它铺墙皮**，所以外观和普通墙一模一样，看不出破绽。

## 3. 接入步骤

### 3.1 刷遮罩

Tile Palette 选 `Mask_Black`，在 `Mask` 层上把**没去过的区域**涂黑。

### 3.2 刷暗墙

Tile Palette 选 `Secret_Logic`，在 `Grid/Logic` 上把要做暗门的墙格涂成青色。
然后选中 `Grid` 按 **Ctrl+Shift+G** 重铺 —— 暗墙会拿到和普通墙一样的墙皮。

### 3.3 建揭示区域

1. Hierarchy 右键 `Grid` → `Create Empty`，命名如 `RevealRegion_Room01`
2. 加 `Box Collider 2D`，勾上 `Is Trigger`
3. 加 `Reveal Region` 组件
4. 用 Scene 视图的绿色手柄把框拉到**覆盖整个房间** —— ⚠️ **必须把暗墙所在格也框进去**，
   否则暗墙的墙皮不会被销毁
5. 把组件上的两个引用拖上：
   - `Mask` → `Grid/Mask`
   - `Secret Walls` → `Grid/Logic` 上的 `SecretWallField`
6. 玩家引用留空即可（会自动找 `PlayerController`）

一个房间一个 `RevealRegion`；所有区域共用同一张 `Mask` 和同一个 `SecretWallField`。

## 4. 机制细节

- **判定不靠物理**：玩家是 Kinematic 刚体 + `Rigidbody2D.Slide`，默认不产生触发回调，
  所以 `RevealRegion` 只是拿 `BoxCollider2D` 当**范围定义**（方便拖手柄），
  判定是比较坐标。框 `Is Trigger` 会在运行时被强制打开，绝不会挡路。
- **只清自己范围**：一个区域只清掉落在自己框内的遮罩格和暗墙格，所以一张遮罩图能服务整个关卡。
- **暗墙墙皮怎么一起消失**：铺装器把 run 在暗墙边界**切开**（一段要么全是暗墙、要么全是普通墙），
  给暗墙那一段的构件挂上 `SecretArt` 标记；揭示时按范围销毁这些构件。
  不切开的话，一段墙皮会横跨两种格子 —— 揭开时要么留残块、要么在正常墙上开洞。
- **一次性**：`RevealRegion` 揭开后不再重复执行。

## 4.5 刷瓦片一定要先选对「目标层」

Tile Palette 窗口左上角有个**目标层下拉框**（默认是当前选中的 Tilemap）。刷子只往目标层写：

- 刷遮罩前，先把目标层切到 `Mask`，再选 `Mask_Black`
- 刷刺 / 暗墙前，目标层切到 `Logic`

**选错会怎样**：遮罩刷进逻辑层后，逻辑层凭空多出一堆「看不见的墙」，
铺装器的外露面判断全歪，表现就是**转角整块没有美术**（这次实际遇到的事故）。

出事了跑这两个菜单（选中 `Grid` 再跑）：

| 菜单 | 作用 |
|---|---|
| `Tools/规则游戏/关卡瓦片/① 体检：逻辑层里有哪些瓦片` | 列出逻辑层里的瓦片；混进遮罩就报警 |
| `Tools/规则游戏/关卡瓦片/② 把遮罩瓦片移回 Mask 层` | 按位置搬回去，然后重铺一次 |

铺装器现在也会**自己认出来**：既没被声明成暗墙、`Collider Type` 又是 `None` 的瓦片，
一律按「不是墙」处理并打警告 —— 所以就算刷错了，也不会再把转角挖掉。

## 5. 容易踩的坑

- ⚠️ **刺不要顶替地板格**。刺不是几何，把地板换成刺玩家会直接掉下去。
  刺要刷在**地板上方那一格**（现在场景里的 49 个刺都是这么放的）。
- ⚠️ **`RevealRegion` 的框要盖住暗墙格**，不然瓦片没了、墙皮还挂着。
- ⚠️ **遮罩层 order 必须高于世界美术**（50），否则没探索的房间会透出来。
- ⚠️ 重铺（Ctrl+Shift+G）会重建 `Art` 和暗墙标记；**遮罩与揭示区域不受影响**，不用重画。
- ⚠️ 遮罩也在 `Grid` 下，`Logic` 的显示开关（Ctrl+Shift+L）不影响它；
  想临时看全图，直接关掉 `Mask` 的 `TilemapRenderer`。

## 6. 验收清单

- [ ] `Mask` 层 order = 50、无碰撞体，未探索区域在 Game 视图里是纯黑
- [ ] `Secret_Logic` 的 Collider Type = `None`（玩家能走穿）
- [ ] 重铺后暗墙的墙皮和相邻普通墙看不出接缝，且该段构件带 `SecretArt`
- [ ] `RevealRegion` 的框覆盖房间 + 暗墙格，两个引用都拖上了
- [ ] 玩家走进房间：遮罩清掉、暗墙瓦片与墙皮同时消失
- [ ] 其他房间仍是黑的（只清自己范围）
