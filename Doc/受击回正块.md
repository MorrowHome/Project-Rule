# 受击回正块（SpringBackBody）

> 一块**可以被攻击击退、然后慢慢回到原位**的活动挡板。
> 它**只在自己的轨道上运动**：打不飞、推不歪、掉不下去。
> 回正速度由**摩擦规则**直接决定：摩擦力越大，回得越慢。

- 组件：`Assets/_Project/Scripts/Gameplay/Scene/SpringBackBody.cs`
- 预制体：`Assets/_Project/Prefabs/SpringBackBody.prefab`（菜单 ⑭ 生成 / 更新）
- 自检：菜单 `规则游戏/验证/回弹块（预制体 + 纯函数）`（编辑期就能跑，32 条断言）

---

## 1. 它解决什么

关卡草图里的那批活动块：竖井 / 走廊里一块挡路的东西，玩家**砍一刀把它推开**，
趁它还没回来挤过去；它慢慢回位、把路重新堵上。
摩擦规则就是这条时间窗的调节旋钮 —— 「摩擦 × 增强」窗口变宽，「× 削弱」窗口变窄。

| 阶段 | 发生什么 | 由谁决定 |
| --- | --- | --- |
| ① 吃击退 | 只读 `DamageInfo.Knockback`，方向 = 水平背离攻击者 + 沿重力反方向抬升，再**投影到轨道** | 攻击方 / `EntityDamageable` 的同一套公式 |
| ② 沿轨道滑出去 | 击退速度按指数衰减；轻击滑约 **0.9 格**、重击滑到**轨道尽头**（默认 ±1.5） | `_knockbackDrag` / 轨道长度 |
| ③ 回正 | 惯性散完后，以「`_returnSpeed` ÷ 摩擦倍率」的速度往锚点走，贴近时减速并吸附 | 摩擦规则 |

⚠️ **回正只在惯性散完之后开始**（`_impulse` 归零）。
如果边飞边拉，「被打飞多远」会被摩擦污染：高摩擦时回正力几乎不刹车，
块反而被推得**更远**（反直觉，且让「摩擦只改回来得快慢」这条设计说不清楚）。

---

## 2. 轨道

轨道是一条**过锚点的直线**，由两个**相对锚点的偏移**定义（世界单位）：

| 字段 | 默认 | 含义 |
| --- | --- | --- |
| `_trackFrom` | `(-1.5, 0)` | 轨道这一端相对锚点的偏移 |
| `_trackTo` | `(1.5, 0)` | 轨道另一端相对锚点的偏移 |

- 位置永远写成 `锚点 + 轴 × 偏移`，偏移被 `Clamp` 在两端之间 —— **块不可能离开轨道**。
- 两端**只用来定方向与范围**；垂直方向的分量会被忽略（块永远在过锚点的那条线上）。
- 两端同号 = 只往一边走（例如 `(0, 0)` → `(0, 3)`：块贴着地面，只能被往上顶）。
- 竖直轨道：填 `(0, -1.5) / (0, 1.5)`。**横向攻击在竖直轨道上只剩抬升那一份**，
  想把块顶得明显就把 `_knockbackLift` 调大（0.6 ~ 1）。
- 白盒：预制体自带一根 `Track` 细条，按配置自动摆好（方向 / 长度 / 位置），
  **接正式美术时清空 `_trackVisual`**；Scene 里还有 Gizmo 画轨道与两端。
- 偏移是**相对锚点**的，所以同一个预制体拖到关卡任何位置都自带正确轨道（不用对世界坐标）。

⚠️ 轨道**不支持带旋转的根物体**（与其余地图组件一致，局部坐标按世界方向算）。

## 3. 摩擦怎么接进来的

读的是 **`IAttributeManager.Values.FrictionScale`** —— 与 `RuleAffectedBody` 改材质摩擦
读的是同一个源，不另起一套；本组件不认识任何规则名。

换算只有一句：**回正速度 = `_returnSpeed` ÷ 摩擦倍率**（倍率夹在 0.25 ~ 3 之间）。

> 块**自己碰撞体上的物理材质摩擦不参与回正** —— 那个值是给站在它上面的人用的
> （`ContactSensor` 读地面材质）。想单独调某一块的快慢，改它自己的 `_returnSpeed`。

| 规则 | FrictionScale | 回正速度倍率 | 轻击（6）回正耗时 | 重击（12） |
| --- | --- | --- | --- | --- |
| 正常 | 1 | 1 | 约 2.6 s | 约 3.2 s |
| 摩擦 × 增强 | 3 | 1/3 | 约 5.9 s | 约 7.5 s |
| 摩擦 × 削弱 | 0.3 | 3（封顶） | 约 1.5 s | 约 1.7 s |
| 摩擦 × 失效 | 0 | 3（封顶） | 约 1.5 s | 约 1.7 s |
| 摩擦 × 反转 | 1 | 1（**不响应**） | 约 2.6 s | 约 3.2 s |

> 耗时来自 **50 Hz 固定步长推演**（与 `FixedUpdate` 是同一段代码 `StepOffset`），
> 包含「击退衰减 ~0.9 s + 回正行程」；Play 里以实测为准。

**为什么不用 Dynamic 刚体 + 引擎摩擦（更「真」的那条路）**：

1. 这类块**悬在竖井里**，脚下没有接触面 —— 引擎摩擦根本不参与，规则对它无效；
2. 就算贴着地，静摩擦上限约 `μ·m·g`，会随「× 增强」涨到 3 倍以上。
   回正力小于它时块会**卡死在偏移位置**、再也回不来，谜题直接锁死。

所以选 **Kinematic + 自己积分 + 轨道约束**（与 `MovingPlatform` / `SpringPlatform` 同一条路线），
摩擦只作为「世界参数」被读进来，单调、有上下限、没有死区。

**为什么「摩擦 × 反转」不响应**：反转的语义是摩擦力的**方向**反过来，只对
**有移动意图**的实体成立（玩家 / 敌人控制器把它读成「按右往左走」）。
回弹块没有意图，把回正方向反过来等于「越推越远」，没有意义 ——
与 `RuleAffectedBody` 对动态物体的处理一致。

## 4. 预制体：四件套缺一不可

| 件 | 值 | 缺了会怎样 |
| --- | --- | --- |
| 实心 `BoxCollider2D` + **Ground 层**（8） | 1 × 1 | 玩家的 `Slide` / 接地只认这一层 —— 放错层就是一块穿得过去的空气 |
| **Kinematic** `Rigidbody2D` | 不吃重力、冻结旋转 | 交给引擎算会掉下去 / 打滚 |
| **受击箱**（`Hurtbox` 子物体，层 10，Trigger） | **和身体同尺寸**（整块可打） | 命中判定只查这一层 —— 没有它就是「砍上去毫无反应」；按 0.75 缩会在宽板上缩出打不到的边距 |
| **轨道**（`Track` 细条 + 两个偏移字段） | 水平 ±1.5 | 没有轨道 = 块会被打飞（这不是它该有的行为） |

- **锚点默认 = 初始位置**（`_anchorAtSpawn`，只在 `Awake` 记一次）。预制体拖进场景直接就能用，不用填坐标。
  锚点**不在启用时重记** —— 分区卸载后重新启用时物体可能还停在被打歪的位置，那时记会把锚点搬过去。
- 受击箱的 `_owner` **显式指到根上的 `SpringBackBody`**：预制体资产里的子物体
  `activeInHierarchy` 是 false，`GetComponentInParent` 在那种状态下找不到父级
  （运行时能找到，但预制体预览 / 验证器里会解析成 null）。
- **没有白盒文字标签**：块上面不挂 `TextMesh`（之前那行「回弹 1.2」已去掉），只剩块本身 + 轨道条。
- 关卡里**拖任意多个**即可，彼此完全独立（每个实例有自己的锚点与轨道）。
- **根物体可以被缩放**（关卡里常做成 8 × 2 的宽板）：受击箱随缩放一起变大、轨道白盒按实际缩放换算，
  编辑模式下拖大也会立刻重算（`[ExecuteAlways]`）。⚠️ **轨道两端仍是世界单位**、不随缩放变 ——
  块变宽了要更长行程，直接改 `_trackFrom` / `_trackTo`。
- ⚠️ **受击箱为什么不按 0.75 缩**（2026-10-18 修）：8 宽的块缩 0.75 后，受击箱边缘缩进身体 **1 米**，
  而玩家从身侧攻击只够得到约 **1.0 米** —— 差几厘米就变成「贴着砍却打不到」，而且左右差一点点就一边能打、
  一边打不到（实测就是这种情况）。整块可打之后两侧都稳定命中。

## 5. 参数

| 参数 | 默认 | 作用 |
| --- | --- | --- |
| `_anchorAtSpawn` | 开 | 锚点 = 初始位置（`Awake` 记一次）；关掉则用上面手填的世界坐标 |
| `_trackFrom` / `_trackTo` | (−1.5,0) / (1.5,0) | 轨道两端（相对锚点的偏移）：方向 + 范围 |
| `_knockbackScale` | 1 | 击退冲量倍率（玩家轻击 6 / 重击 12 / 敌人 7） |
| `_maxKnockbackSpeed` | 14 | 沿轨道击退速度上限 |
| `_knockbackDrag` | 6 | 击退衰减（每秒，指数）。越小滑得越远 |
| `_knockbackLift` | 0.3 | 击退方向抬升量（1 = 纯向上，跟随重力反转）；**竖直轨道主要靠它推** |
| `_returnSpeed` | 1.2 | **摩擦正常时**的回正速度（格 / 秒） |
| `_returnEaseDistance` | 0.5 | 离锚点这么近开始减速（避免「啪」地停住） |
| `_settleDistance` | 0.02 | 这么近 + 没惯性 → 精确吸附 |
| `_minReturnMultiplier` | 0.25 | 高摩擦时的回正速度下限倍率 |
| `_maxReturnMultiplier` | 3 | 低摩擦时的回正速度上限倍率 |
| `_trackVisual` | 预制体里的 Track | 白盒轨道条；**接正式美术时清空** |

## 6. 与战斗链路的关系

- **命中只认受击箱**：`CombatSystem.PerformAttack` → `Hurtbox.Mask` → `Hurtbox.ResolveOwner`
  → `SpringBackBody`（`IDamageable`）。
- **准入**：块没有阵营（`IFactionMember`），`CombatSystem.CanHit` 对「一方无阵营」放行 ——
  玩家和敌人都能打它。
- **只吃击退、不掉血**：`ApplyDamage` 直接忽略 `Amount`。它是机关，不是敌人 ——
  没有 `EntityStatus`、没有无敌帧、没有死亡。
- **站在块上打别人，脚下的块不会跟着弹开**（2026-10-18 修）：攻击盒是「从身体中心往前」的横盒，
  站在块顶挥刀时它的下沿会贴着 / 压进脚下这块的受击箱，Box2D 的重叠判定**含边界**，
  于是两块一起被推。现在 `ApplyDamage` 先做**脚底探测**（脚底扁盒里有没有我的实心碰撞体）：
  是就整下忽略 —— 那不是「在打我」，是打别人。详见 `IsRiddenBy`。
- **伤害挂账**（`DamageDeferred`）期间：伤害记 0、**击退照常下发**，块照样被推。
- **因果**：因果反转会把伤害转到发起方自己身上，不经过这里；
  因果扩散 / 作用对象随机**不会**选中它 —— 它没有登记 `WorldRegistry`。
- **暂停**：`TimeManager.IsPaused` 时位置冻结。
- **时间规则**：积分用 `Time.fixedDeltaTime`，随 `Time.timeScale` 缩放。
- **承载**：实现了 `IMovingSurface`，站在块上的实体沿轨道被带走。

## 7. 已知限制

- **只能沿轨道走**：垂直轨道方向的分量被吃掉；斜着的攻击只有投影那一份推得动它。
- **不能离开轨道去挡别的路**：轨道就是它的全部活动范围（这既是约束也是关卡设计的边界）。
- **不参与时间回溯**（与其余地图组件一致，没挂 `ISnapshotParticipant`）。
- **会把挡路的玩家推着走**（2026-10-19 修）：块移动前先算「这一帧的位移会不会把人顶进墙里」
  （`SafeFraction`，与电梯 `CityPathMotor` 同一套），再把夹短后的位移通过
  `PlayerController.CarryOnPlatform` 交给玩家 —— 人跟着块走，块不会坐进人身体里。
  **推不动就停**：悬空 / 上升中 / 顶着墙的玩家会让块停住，等他们让开再继续，不会卡人。
- **块自己仍会穿墙**：轨道要摆在空腔里（两端也别顶进墙里）—— 墙只用来夹"玩家的那份位移"，
  块自身没做墙体检测。
- **敌人还不会被推**：敌人没有承载入口（`EnemyMotor` 没有 CarryOnPlatform），块对敌人仍是穿过。
- **不能推**：不实现 `IPushable`，玩家顶它不会动（只有攻击能推动）。
- **锚点固定**：块只回一个点，不跟随移动平台（要挂在移动平台上，另做）。
- **根物体不要旋转**：轨道白盒与位移都按世界方向算。

## 8. 怎么验

1. 菜单 `规则游戏/验证/回弹块（预制体 + 纯函数）` → Console 应显示 **32 通过 / 0 失败**：
   摩擦倍率换算、单调性、击退方向、**轨道投影**、预制体四件套、轨道内运动积分
   （推多远 / 回正 / 轨道限位 / 吸附 / 速度上报）。
2. Play 里：**左右各砍一刀**都要有效 → 块**沿轨道**退开（轻击 ~0.9 格、重击顶到轨道尽头），停一下、慢慢回来；
   侧面推到轨道外也推不动（只会沿轨道滑）。放一条「摩擦 × 增强」→ 回来明显更慢。
3. 站在块顶上等它回正 → 人跟着一起走（`IMovingSurface`）。
4. **站在 A 块上砍 B 块** → 只有 B 退开，脚下的 A 纹丝不动（这是 `IsRiddenBy` 在起作用）；
   跳到空中再砍 A → A 照常被推（脚底没踩实）。

## 9. 还能接什么

- `OnKnockedBack` 事件（参数是沿轨道加进来的冲量）→ 受击 VFX / 音效 / 屏幕抖动。
- 正式美术：替换 `Art` 子物体的 sprite、清空 `_trackVisual`（玩法判定都不读它们）。
- 想做「被推到某个位置就触发机关」：轮询 `Displacement`，加 `UnityEvent`，别改运动本身。
- 需要它参与时间回溯时：挂 `ISnapshotParticipant` 存 `_offset` / `_impulse` —— 那是另一件事。
